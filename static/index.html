Connect your workspace and select a SQL warehouse. Workspace authentication and warehouse access are tested separately. Deploy converted SQL from the Deploy to Databricks section.

Install the Databricks CLI on the machine running this app, then authenticate there:

databricks auth login --host <workspace-url>

The app uses databricks auth token for the saved host/profile. It does not launch an interactive login or store CLI tokens.

Set DATABRICKS_HOST and DATABRICKS_TOKEN in the app server environment, then restart it. DATABRICKS_HOST must exactly match this workspace. The token value is never displayed here.
